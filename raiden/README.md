# ⚡ RAIDEN 雷电 · 双人街机重制版

致敬 1990 年 Seibu Kaihatsu 街机《Raiden》的粉丝重制版：官方 8 大关卡 + 8 位 Boss + 强化武器系统 + 同屏双人协作。

## 启动

```bash
cd raiden
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

## 玩法

| 项目 | 说明 |
|---|---|
| P1（红） | WASD 移动 · J / Space 射击（按住蓄力 Overdrive）· K 炸弹 |
| P2（蓝） | 方向键移动 · `,` 射击 · `.` 炸弹 |
| 通用 | P 暂停 · M 回菜单 · 回车投币续关 · 支持手柄/触屏（拖动P1） |

## 武器系统（MAX Lv.8 + 蓄力爆发）

- **V 火神炮**：扇形弹幕，满级 8 向 + 贯穿
- **L 激光**：可弯曲粗光束，贴脸爆发最高
- **E 等离子**（新增）：追踪电浆，穿透
- **M** 切换导弹（追踪 ↔ 核弹）· **O** 僚机 · **B** 雷电炸弹（清屏+重创Boss）
- **P** 升级；死亡保留一半等级，不再清零
- 拾取：★勋章连击加分 · 🧚仙女 +5000 · 🐄隐藏米克鲁斯 +100000

## 出怪与难度设计（固定套路 + 随机涓流）

- 每关 27~30 个**固定波次**（`js/waves.js`），约每 2~4 秒一波、从 t=2 铺到 t=86：V字侦察、横排蛇形、侧翼切入、装甲横列、炮艇护航、自杀机群、航母编队等，每波有中文预告，同一关每次都一样、可背板；S1 约 146 架、S8 约 223 架，加上涓流每关共约 170~260 架
- 每 1.6~2.8 秒一股**随机涓流**（1~3 架，可从侧翼切入），填补波次间隙直至 Boss；turret/gunboat/carrier 等重型单位只走固定脚本；Boss 战约在 90 秒
- 火力压制：杂兵开火间隔 2.2~3.4 秒（按机型区分），扇形弹 2~3 发，敌弹速随关卡缓增、双人再降速，全局敌弹硬上限 220（Boss 战 260），同屏过挤时敌机哑火
- 掉落：固定波次中穿插 P/M/B/O/S 补给，载具（坦克/航母）必掉倾向更高
